# Week 1 - Day 1 SQL Practice

## Overview
Today’s work focused on understanding the fundamentals of SQL and practicing basic database operations using DB-Fiddle. I created tables, inserted sample data, and solved SQL queries based on employee, department, and project management datasets.

---

## What I Learned

### SQL Fundamentals
- Understanding relational databases and tables
- Difference between rows and columns
- Importance of primary keys and foreign keys

### Database Setup
- Creating tables using `CREATE TABLE`
- Inserting records using `INSERT INTO`
- Working with multiple related tables

### Data Retrieval
- Using `SELECT` statements to fetch data
- Retrieving specific columns from tables
- Filtering records using `WHERE`

### Pattern Matching
- Using `LIKE` operator with:
  - `%` wildcard
  - `_` wildcard
- Searching records based on patterns in strings

### Date Operations
- Filtering records using dates
- Using functions like:
  - `YEAR()`
  - `MONTH()`
  - `DATE_SUB()`

### Aggregate Functions
- Calculating:
  - `SUM()`
  - `AVG()`
  - `MIN()`
  - `COUNT()`

### Grouping Data
- Using `GROUP BY` for department-wise analysis
- Calculating grouped averages and totals

### Joins
- Understanding relationships between tables
- Using `INNER JOIN` to combine data from multiple tables
